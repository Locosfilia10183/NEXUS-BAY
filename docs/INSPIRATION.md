Collected visual and system references for NEXUS-BAY.

| Name | Description | Priority |
|------|-------------|----------|

## Systems inspired by Cursed Bay style
- **Crew Skill Tree** – shared progression for the whole crew
- **Weapon Skill Trees** – separate trees for swords, guns, pistols, harpoons
- **Logbook / Quests** – player, daily, weekly, crew, server, feats
- **Classes** – simple role system that fits pirate fantasy
- **Custom items & ores** – silver, special gems, pirate-themed gear (later)

## Atmosphere keywords
Tropical islands, turquoise water, weathered wood, lanterns, smoke, skull banners, red-white stripes, purple cursed portals, gold treasure, sunsets, ship masts, hanging chains, waterfalls.

These are design targets, not requirements for the first technical release.
