# NEXUS-BAY Theme – Pirate Bay / Cursed Bay

NEXUS-BAY is a **pirate-themed Minecraft network** (Java + Bedrock).
Inspiration: Caribbean bays, cursed islands, lighthouses, shipwrecks, taverns, treasure chambers, pirate portals and crew systems.

## Visual direction

- **Colors:** deep blues, turquoise water, weathered wood, sandstone, red/white stripes, black flags, purple/cursed accents, gold treasure
- **Key structures (build targets):**
  - Classic red-white lighthouse + dark/cursed lava lighthouse
  - Rum tavern / pirate tavern (wood, barrels, lanterns, skull banners)
  - Barrel house (Fasshaus)
  - Treasure chamber (Schatzkammer) with diamond/gold displays
  - Pirate portal (skull gate + purple portal)
  - Shipwreck base / docked ships
  - Skull cliff / Totenkopfklippe
  - Cursed fortress in ash/lava biome
  - Harbor towns with red roofs and docks
- **Atmosphere:** tropical islands + mysterious/cursed zones, lantern light, smoke, waterfalls, hanging chains

## Gameplay pillars (aligned with inspiration)

1. **Crews** – create/join crews, ranks, shared skill tree, crew quests, shared bank
2. **Weapon mastery skill trees** – swords/sabres, rifles, pistols, harpoons (progressive unlocks)
3. **Quests / Logbook** – daily, weekly, crew and story quests
4. **Progression** – player level + class/role + crew level
5. **Exploration** – tropical islands, ash/cursed biome, shipwrecks, hidden caves, treasure rooms
6. **Economy** – Bay-Coins, player shops, auction, taxes
7. **PvE & instances** – dungeons, bosses, keys, repeatable content

## What is NOT in the first technical foundation

Custom 3D models, full devil-fruit systems, complex Haki combat, complete marketplace UI and large pre-built maps are later phases. The current core delivers network infrastructure, profiles, basic islands, admin tools and the data model for the systems above.

## Reference mood

Think „Cursed Bay“ meets classic pirate adventure: warm sunsets, lantern-lit taverns, skull portals, crew skill trees and a living harbor lobby that feels like a real pirate bay.
